# JY Studio

기업 홈페이지·쇼핑몰·브랜드 웹사이트 제작을 소개하는 서지영의 1인 웹디자인·개발 스튜디오 사이트입니다. HTML, CSS, JavaScript만 사용하며 별도 패키지 설치나 빌드 단계는 없습니다.

## 로컬 실행

이 README가 있는 폴더에서 실행합니다.

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

기존 정적 사이트 배포 구조와 문서 루트는 그대로 유지합니다. `index.html`, `en.html`, `style.css`, `script.js`, `assets`를 함께 배포하세요.

## 콘텐츠 관리

- 화면 순서: 메인 → 스튜디오 소개 → 프로젝트 → 제작 과정 → 문의
- 태경물산 카페24·웹 버전은 실제 고객 프로젝트입니다. UNFORM은 개인 콘셉트 프로젝트입니다. NOVERA와 NEXCORE는 고객 실적으로 단정하지 않는 포트폴리오 작업입니다.
- 기존 프로젝트 5개와 외부 사이트 링크를 유지합니다. 프로젝트의 목적·담당 작업·기술·구현 내용을 함께 안내합니다.
- 이메일은 `yg03166@naver.com`을 사용합니다. PC의 카카오톡 버튼은 채널 홈 `https://pf.kakao.com/_dqbWX`으로 연결하고, 터치 중심 모바일 환경에서는 사용자가 제공한 채팅 바로가기 `https://pf.kakao.com/_dqbWX/chat`으로 연결합니다. PC에서 채팅을 이용하기 어려울 때는 이메일로 문의하도록 안내합니다.
- 실제 구현 범위가 확인되지 않은 결제·회원·관리 기능, 고객 후기, 경력, 성과 수치는 기재하지 않습니다.

## 이미지

화면에는 최장변 1,600px 이하의 WebP 파일을 사용합니다. 기존 JPG·PNG 원본은 보존했습니다.

- 큰 프로필: `assets/images/s1.webp`
- 작은 프로필: `assets/images/s2.webp`
- 프로젝트: `unform.webp`, `novera.webp`, `TK2.webp`, `TK1.webp`, `NEXCORE.webp`

사진을 교체할 때는 실제로 참조하는 WebP도 함께 갱신하고 `index.html`의 이미지 설명과 원본 가로·세로 치수를 확인하세요. 화면 크롭은 CSS에서 제어합니다.

## 검증

```sh
node --check script.js
git diff --check
```

브라우저에서는 PC·태블릿·모바일의 가로 넘침, 이미지 로딩, 모바일 메뉴의 열기·닫기·Escape·키보드 탐색, 내부 링크, 모션 감소 설정을 확인합니다. JavaScript를 끄더라도 본문과 기본 문의 링크는 표시됩니다. IntersectionObserver 애니메이션은 모션 감소 설정에서 비활성화됩니다.

## 언어 페이지

- `index.html`: 한국어 / `en.html`: 영어. 동일한 CSS·JavaScript·이미지를 공유합니다.
- 헤더의 `KO / EN` 링크로 전환합니다. JavaScript 사용 시 현재 섹션 주소도 유지합니다.
- 영어 페이지는 별도의 정적 HTML이라 외부 번역 서비스 없이 열리고, JavaScript를 끈 경우에도 영어 콘텐츠를 제공합니다.
- 콘텐츠를 갱신할 때는 한국어·영어의 대응 내용, 페이지별 메타데이터·이미지 설명·메뉴 접근성 문구를 함께 확인하세요.

## 메인 비주얼과 모션

- 메인에는 생성한 흑백 꽃·실크 패브릭 오브제 이미지 `assets/images/studio-cosmos.webp`를 사용합니다. 기존 NOVERA 프로젝트는 작은 미리보기와 원래 링크로 유지합니다.
- 요청에 따라 서비스 소개 영역과 연결 메뉴는 제거했습니다. 기존 프로젝트 5개는 유지합니다.
- 한국어·본문은 Pretendard, 영문 디스플레이는 Cormorant Garamond를 사용합니다. 폰트와 라이선스는 `assets/fonts`에 포함되어 있으므로 배포할 때 해당 폴더도 포함하세요.
- 배경은 블랙·화이트 우주 테마입니다. Canvas 별빛과 간헐적인 유성 효과를 사용하며 PC는 약 25fps, 모바일은 약 15fps로 제한합니다. 백그라운드에서는 중지하고, 모션 감소 설정에서는 정지된 별 배경만 표시합니다. PC 마우스에는 빛나는 점·링·별빛 잔상을 적용하며 모바일·키보드 탐색·모션 감소·고대비 환경에서는 기본 커서를 유지합니다. 장식 레이어는 입력을 가로채지 않습니다.

## 배경 음악

- `music.js`와 `assets/audio/studio-deep-house.mp3`를 함께 배포합니다. 외부 서비스 없이 재생되는 자체 제작 118 BPM 딥하우스 루프입니다.
- 기본 볼륨은 25%입니다. 브라우저에서 허용하면 진입 시 자동재생을 시도하고, 차단되면 첫 클릭·터치 또는 재생 버튼으로 시작합니다.
- 오른쪽 아래 플레이어에서 재생·일시정지·볼륨을 조절할 수 있습니다. 모바일에서는 고정 문의 버튼 위에 표시합니다.
- 재생 끄기·볼륨·재생 위치는 로컬 저장소에 보관해 한국어·영어 전환과 재방문 시 이어집니다. 백그라운드 탭에서는 일시정지합니다. 브라우저/운영체제에서 음악을 정지한 경우에도 다시 켜기 전까지 유지합니다.
- 음원 정보와 오프라인 재생성 방법은 `assets/audio/README.md`에 있습니다. 생성 도구는 사이트 실행 시 필요하지 않습니다.

```sh
node --check music.js
```
