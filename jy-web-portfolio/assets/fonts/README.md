# Studio fonts

- `PretendardVariable.woff2`: Pretendard v1.3.9 by Kil Hyung-jin, SIL Open Font License. Original distribution: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable
- `CormorantGaramond-Latin.woff2`: Latin and punctuation subset of the Cormorant Garamond variable font from Google Fonts, SIL Open Font License. Original source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

License texts are included beside the fonts. Both fonts are served locally with `font-display: swap`; no external font service is required. The Cormorant subset retains its variable weight axis (300–700).
